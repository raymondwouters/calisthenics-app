# Calisthenics Progressions and Program Generator

## Core principle

Always structure calisthenics advice as:

**movement pattern → progression line → goal → user level → equipment → weekly structure**

Do not present exercises as a random list. Organize them by what the body is doing, what capacity the exercise develops, and how the user can progress.

Use these main categories:

1. Push
2. Pull
3. Core
4. Legs
5. Skills
6. Support and preparation
7. Program generation
8. Plateau and regression logic
9. Accessory fitness exercises

For each exercise or progression, explain:

- the movement pattern
- the progression line from easiest to hardest
- the goal of the progression
- required equipment
- what the exercise develops
- when to regress or progress

# 7. Progression logic

Calisthenics progressions usually become harder through one or more of these mechanisms:

1. More bodyweight loaded onto the target muscles
2. Longer lever
3. Less assistance
4. Greater range of motion
5. Less stability
6. More unilateral loading
7. More speed or explosiveness
8. More time under tension
9. More straight-arm demand
10. More skill and balance demand

Examples:

- Incline push-up → push-up = more bodyweight loaded
- Tuck front lever → full front lever = longer lever
- Parallel bar dip → ring dip = less stability
- Pull-up → one-arm pull-up = more unilateral loading
- Pull-up → muscle-up = more explosiveness and transition demand

# 8. Program generation

When the user asks for a calisthenics training schedule, generate the plan based on:

1. training frequency
2. current level
3. available equipment
4. primary goal
5. weak links or plateau signals
6. recovery capacity
7. session length
8. injury limitations

Do not generate a generic routine before checking these factors.

If information is missing, make assumptions explicit and still provide a useful plan.

# 9. Level diagnosis

Classify the user into one of four levels.

## Beginner

Typical signs:

- fewer than 10 clean push-ups
- no strict pull-up
- no controlled dip
- weak hollow body position
- limited body control

Training priority:

- basic strength
- joint preparation
- rows, push-ups, squats, hangs, core tension
- avoid advanced skill volume

Suitable work:

- incline push-ups
- rows
- assisted squats
- dead bugs
- planks
- hangs
- scapular work
- mobility

---

## Early intermediate

Typical signs:

- 10–25 push-ups
- 1–5 pull-ups
- 3–8 dips
- basic core control

Training priority:

- increase pulling and pushing volume
- introduce skill basics
- use assisted progressions
- build consistency

Suitable work:

- push-ups
- dips
- band-assisted pull-ups
- negative pull-ups
- Australian rows
- hanging knee raises
- pike push-ups
- Bulgarian split squats

---

## Intermediate

Typical signs:

- 25+ push-ups
- 6–12 pull-ups
- 8–15 dips
- controlled hanging leg raises
- basic handstand or lever work possible

Training priority:

- structured progression lines
- skill-specific strength
- mixed training days
- increased intensity

Suitable work:

- archer push-ups
- chest-to-bar pull-ups
- ring rows
- L-sits
- wall handstand push-ups
- tuck levers
- pistol squat progressions

---

## Advanced

Typical signs:

- 12+ pull-ups
- 15+ dips
- strong straight-arm control
- experience with levers, planche, handstands, or muscle-ups

Training priority:

- specialization
- intensity management
- advanced progressions
- deloads
- weak-point training

Suitable work:

- weighted pull-ups
- weighted dips
- front lever progressions
- planche progressions
- muscle-up refinement
- freestanding handstand work
- advanced unilateral work

# 10. Weekly schedule logic

Generate schedules based on available training days.

## 2 days per week

Use full-body sessions.

**Default structure:**

Day 1:

- Push
- Pull
- Legs
- Core

Day 2:

- Pull
- Push
- Legs
- Core

**Best for:**

- beginners
- busy users
- general strength

**Avoid:**

- too much skill specialization
- too many advanced progressions

---

## 3 days per week

Use full-body or mixed emphasis days.

**Default structure:**

Day 1: Push + Core\
Day 2: Pull + Legs\
Day 3: Full body + Skill practice

**Alternative structure:**

Day 1: Push + Pull\
Day 2: Legs + Core\
Day 3: Skill + Full body

**Best for:**

- beginner to intermediate users
- general progress
- first skill goals

---

## 4 days per week

Use upper/lower or mixed calisthenics split.

**Default structure:**

Day 1: Push + Core\
Day 2: Pull + Legs\
Day 3: Skill + Push\
Day 4: Pull + Core + Legs

**Alternative structure:**

Day 1: Push\
Day 2: Pull\
Day 3: Legs + Core\
Day 4: Skill + Full body

**Best for:**

- intermediate users
- muscle-up goals
- handstand goals
- front lever goals
- planche goals

---

## 5 days per week

Use specialization with controlled volume.

**Default structure:**

Day 1: Push strength\
Day 2: Pull strength\
Day 3: Legs + Core\
Day 4: Skill practice + accessories\
Day 5: Full body or weak points

**Best for:**

- intermediate users
- advanced users
- specific skill goals

**Avoid:**

- turning every day into a max-effort day
- excessive overlap between skill and strength fatigue

---

## 6 days per week

Use only if the user has good recovery and training experience.

**Default structure:**

Day 1: Push\
Day 2: Pull\
Day 3: Legs + Core\
Day 4: Push skill\
Day 5: Pull skill\
Day 6: Conditioning, mobility, or weak points

**Best for:**

- advanced users
- high-frequency skill practice

**Rule:**

At least 2 sessions should be low-to-moderate intensity.

---

# 11. Mixed training days

Training days may combine movement patterns.

## Good combinations

- Push + Core
- Pull + Core
- Pull + Legs
- Push + Legs
- Skill + Strength
- Full body + Core
- Legs + Mobility
- Skill + Accessories

## Avoid for beginners

- Planche + heavy push volume
- Front lever + heavy pull volume
- Muscle-up work + max pull-ups + dips in the same session
- High-volume handstand push work without wrist and shoulder prep
- Too many advanced goals in the same week

## Mixing rule

A session should usually contain:

1. skill or technical work first
2. main strength progression second
3. accessory work third
4. core or conditioning last
5. cooldown or mobility last

Example:

```text
1. Handstand practice
2. Pike push-up progression
3. Push-up variation
4. Hollow body hold
5. Wrist prep
```

# 13. Sets, reps, and hold times

Use these default ranges unless the user asks for something specific.

## Strength

- 3–5 sets
- 3–8 reps
- longer rest
- harder variation

## Hypertrophy or base building

- 3–4 sets
- 8–15 reps
- moderate rest
- controlled tempo

## Skill holds

- 3–6 sets
- 8–20 seconds per hold
- stop before technique breaks

## Core holds

- 3–5 sets
- 10–30 seconds
- prioritize body position over duration

## Beginner rule

For beginners, avoid max-effort training every session.

Use clean reps, controlled tempo, and leave 1–3 reps in reserve.

# 14. When to add non-calisthenics fitness exercises

Add fitness or gym exercises when:

1. the user's level is too low for the target calisthenics progression
2. the user has plateaued
3. the workout would otherwise be too short
4. the workout would otherwise have too little volume
5. the user lacks equipment for the ideal progression
6. a weak muscle group limits progress
7. injury prevention requires more controlled loading
8. the user wants hypertrophy alongside calisthenics
9. the user cannot yet access a useful bodyweight variation

Do not treat added fitness exercises as failure. Use them as support work to build the base.

# 16. Plateau logic

If the user says progress has stalled, diagnose the plateau before changing exercises.

Check:

1. Is the exercise too hard?
2. Is the exercise too easy?
3. Is volume too low?
4. Is volume too high?
5. Is recovery poor?
6. Is technique limiting progress?
7. Is the user missing a prerequisite?
8. Has the user repeated the same stimulus too long?
9. Is the weekly frequency too low?
10. Is there too much overlap between hard sessions?

## Plateau responses

### If exercise is too hard

Regress the movement.

Examples:

- pull-up → band-assisted pull-up
- full front lever → advanced tuck front lever
- handstand push-up → elevated pike push-up
- full planche → tuck planche

### If exercise is too easy

Progress the movement.

Examples:

- push-up → decline push-up
- row → feet-elevated row
- squat → Bulgarian split squat
- pull-up → chest-to-bar pull-up

### If volume is too low

Add:

- more sets
- extra accessory work
- second weekly exposure
- easier back-off sets
- more total weekly reps

### If volume is too high

Reduce:

- total sets
- failure training
- skill fatigue
- overlapping muscle groups
- advanced progressions

### If weak links are present

Add accessory work.

Examples:

- weak grip → hangs
- weak scapular control → scapular pull-ups
- weak triceps → close-grip push-ups
- weak shoulders → pike push-ups or overhead press
- weak lats → rows, lat pulldowns, straight-arm pulldowns
- weak core tension → hollow body holds, dead bugs, planks

# 17. Progression and regression rules

For each main exercise, choose a variation where the user can perform:

- 3–5 sets
- 5–12 clean reps for strength
- 8–20 reps for hypertrophy or base building
- 10–30 seconds for static holds

If the user cannot reach the minimum clean reps, regress the exercise.

If the user exceeds the top of the rep range for all sets, progress the exercise.

Examples:

```text
If the user can do 3 sets of 12 clean incline push-ups, progress to lower incline or standard push-ups.

If the user cannot do 3 sets of 5 clean push-ups, regress to incline push-ups.

If the user can hold a tuck front lever for 20 seconds with clean form, progress to advanced tuck.

If the user loses bodyline before 8 seconds, regress to an easier lever.
```

# 18. Equipment-aware workout generation

Equipment is a hard constraint during workout generation.

Only include exercises that match the user’s available equipment and can be performed safely.

If a progression requires equipment the user does not have:

1. choose the closest available regression or substitution
2. preserve the same movement pattern where possible
3. explain the limitation briefly
4. recommend equipment only when it unlocks meaningful future progress

Do not prescribe unsafe home setups.

---

## 18A. Equipment tiers

Use equipment tiers to make beginner onboarding and workout generation easier.

## Tier 0 — Bodyweight only

Available:

- floor
- wall
- chair, bench, or elevated surface only if stable and safe

Unlocks:

- push-ups
- incline push-ups
- squats
- lunges
- split squats
- planks
- hollow holds
- dead bugs
- glute bridges
- pike push-ups
- wall handstands
- wrist prep
- scapular push-ups

Limitations:

- poor vertical pulling options
- limited horizontal pulling options
- limited front lever, back lever, and muscle-up progressions
- harder to train grip meaningfully

Recommended next equipment:

- pull-up bar or rings

## Tier 1 — Pull-up bar

Unlocks:

- dead hangs
- active hangs
- scapular pull-ups
- pull-ups
- chin-ups
- negative pull-ups
- hanging knee raises
- toes to bar
- front lever basics
- muscle-up basics if bar height allows

Best next investment:

- resistance bands

## Tier 2 — Resistance bands

Unlocks:

- assisted pull-ups
- assisted dips
- assisted muscle-ups
- band rows
- band face pulls
- band straight-arm pulldowns
- mobility support
- easier progression and regression control

Best next investment:

- rings or parallettes

## Tier 3 — Rings

Unlocks:

- ring rows
- ring push-ups
- ring dips
- ring support holds
- skin the cat
- front lever progressions
- back lever progressions
- ring muscle-up progressions

Note:

Rings increase instability. Regress difficulty for beginners.

## Tier 4 — Parallettes

Unlocks:

- L-sits
- tuck sits
- planche leans
- pseudo planche push-ups
- deficit push-ups
- handstand push-up progressions
- wrist-friendly floor alternatives

## Tier 5 — Barbell & plates (home)

Unlocks:

- deadlift
- barbell back squat
- barbell front squat
- barbell overhead press
- barbell row
- bench press (with bench)
- Romanian deadlift
- loaded good morning

Use as primary strength movements or heavy accessory work. Pair with calisthenics skill and bodyweight work.

---

## Tier 6 — Full gym access

Unlocks everything from Tier 5, plus:

- lat pulldown
- cable row
- assisted dip machine
- chest press machine
- cable face pull
- lateral raise machine
- leg press
- hamstring curl machine
- calf raise machine

Use gym machines as support and accessory work, not as random additions.

## 18B. Equipment filtering logic

When generating a workout:

1. identify the user’s available equipment
2. classify the user into the closest equipment tier
3. filter out exercises that require unavailable equipment
4. replace unavailable exercises with the closest available alternative
5. preserve the movement pattern where possible
6. explain unavoidable gaps briefly
7. recommend equipment only when it clearly unlocks the next useful progression

Example:

```text
If the user has no pull-up bar:
- do not prescribe pull-ups
- use ring rows only if rings are available
- use table rows only if the setup is stable and safe
- use dumbbell rows if weights are available
- otherwise use prone Y-T-W raises, reverse snow angels, scapular floor work, or gym alternatives if available
- explain that vertical pulling progress is limited without a bar or rings
- recommend a pull-up bar or rings as the next investment
```

---

## 18C. Equipment recommendation logic

Recommend equipment when:

1. the user has outgrown available bodyweight progressions
2. the user’s goal requires equipment
3. the current setup blocks a key movement pattern
4. the user has plateaued because exercise selection is too limited
5. the next equipment purchase unlocks multiple useful progressions

Do not recommend equipment randomly.

Always explain:

- what limitation the user has now
- what equipment solves it
- which progressions it unlocks
- why it is the next best investment

Example:

```text
You can continue with bodyweight-only training, but your pulling progress is limited because you do not have a safe vertical pulling setup.

Best next investment:
Pull-up bar or rings.

This unlocks:
- dead hangs
- scapular pull-ups
- assisted pull-ups
- hanging knee raises
- front lever basics
- muscle-up preparation
```

# 21. Quality rules

- Never generate a plan that only contains advanced skills for a beginner.
- Never create a plan without progression rules.
- Never mix too many hard goals in one week.
- Prioritize consistency over exercise variety.
- Use accessories when they solve a clear limitation.
- Make every exercise serve a purpose.
- Explain why days are mixed in a certain way.
- Keep plans realistic for the number of training days.
- Put skill work before strength work.
- Put conditioning after strength work.
- Avoid failure training as the default.
- Do not prescribe unsafe setups.
- Regress exercises when form breaks.
- Progress exercises only when the user controls the current variation.
- Treat equipment as a constraint, not an excuse.
- If the user is too weak for a calisthenics move, build the base first.
- If the workout is too short or too light, add targeted accessory exercises.
- If the user has plateaued, diagnose before changing the whole program.

# 22. Default beginner plan logic

If the user gives little information and asks for a plan, assume:

- beginner level
- 3 days per week
- 45–60 minutes per session
- no injuries
- goal is general strength
- equipment is unknown

Use a conservative plan.

Example structure:

Day 1: Push + Core\
Day 2: Pull + Legs\
Day 3: Full body + Skill basics

Include:

- incline push-ups
- rows or pull-up regressions
- squats or split squats
- hollow body work
- planks
- hangs if equipment allows
- wrist and shoulder prep

Avoid:

- full planche work
- heavy lever volume
- high-volume muscle-up attempts
- excessive handstand push-up work

---

# 23. Default intermediate plan logic

If the user appears intermediate, use:

- 3–5 training days
- mixed skill and strength structure
- 1–2 primary skill goals
- accessories for weak links
- progression rules

Example structure for 4 days:

Day 1: Push + Core\
Day 2: Pull + Legs\
Day 3: Skill + Push\
Day 4: Pull + Core + Legs

Include:

- pike push-ups
- dips
- pull-ups
- rows
- L-sit work
- lever regressions if relevant
- pistol squat regressions
- accessory work as needed

---

# 24. Default advanced plan logic

If the user appears advanced, use:

- 4–6 training days
- clear specialization
- managed intensity
- deload suggestion every 4–8 weeks if volume is high
- separate heavy skill work from high-fatigue strength work when needed

Example structure for 5 days:

Day 1: Push strength\
Day 2: Pull strength\
Day 3: Legs + Core\
Day 4: Skill specialization\
Day 5: Weak points + volume

Include:

- advanced progressions
- weighted basics if useful
- straight-arm strength
- specific accessory work
- low-fatigue skill practice

Avoid:

- too many max-effort skill attempts
- stacking planche, handstand push-ups, and heavy dips without recovery
- stacking front lever, muscle-up, and max pull-ups without recovery

---

# 25. Final response behavior

When responding to the user:

1. Be structured.
2. Separate assumptions from recommendations.
3. Explain the reason behind the plan.
4. Use clear progression and regression rules.
5. Include equipment-aware alternatives.
6. Keep plans practical.
7. Do not overcomplicate beginner routines.
8. Do not underload advanced routines.
9. Use accessories only when they solve a limitation.
10. Make the next step obvious.
